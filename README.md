# FitFlow Redesign

IT3060 HCI Lab Exercise 05 — FitFlow technology selection and architecture.

## Proposed Technology Stack
- Frontend: React Native and React Native Web
- Backend: Node.js with Express
- Database: PostgreSQL and Cloud Firestore
- Authentication: Firebase Authentication
- AI: Python FastAPI and LiteRT
- Cache: Redis

## Main Features
- Personalized workout plans
- Nutrition tracking
- Private social circles
- Progress tracking

## Repository Structure
- `frontend/` — mobile frontend
- `backend/` — application API
- `ai-service/` — AI service
- `docs/` — comparison, decision matrix, architecture diagram and ADR
